# Airbnb Data Wrangling

## Beginner Mini Project

This is a simple Data Wrangling project created using:

- Python
- Pandas
- Matplotlib
- Streamlit

## Project Overview

This project uses Airbnb listing data to demonstrate basic
data-wrangling and data-visualization techniques.

The project allows users to load, inspect, clean and analyze
Airbnb data through a simple Streamlit application.

## Pages

### Page 1 — Home

Introduction and project objectives.

### Page 2 — Load Data

Learn:

- read_csv()
- head()
- shape
- dtypes
- isnull()
- describe()
- duplicated()

### Page 3 — Clean Data

Learn:

- drop_duplicates()
- fillna()
- mean()
- median()
- mode()

The page cleans missing Airbnb values and removes duplicate listings.

### Page 4 — Airbnb Price Analysis

Learn:

- value_counts()
- pd.cut()
- groupby()
- Average price analysis
- Price categories

The Airbnb listings are divided into:

- Budget
- Moderate
- Premium
- Luxury

The page also compares average prices by property type
and location.

### Page 5 — Charts

Learn:

- Bar chart
- Histogram
- Scatter plot

The project creates visualizations for:

- Property type distribution
- Price distribution
- Price vs Number of Reviews
- Price vs Review Score
- Average price by location

## Installation

Install Python 3.10 or newer.

Open Command Prompt/Terminal in this project folder.

Run:

bash
